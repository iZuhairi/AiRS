Project Introduction

Automated Incident Response System for Enterprise Infrastructure

Problem Statement

1. Manual Incident Delay

Traditional incident response heavily relies on human intervention. The latency between alert reception, logging into the CLI, and manual mitigation leaves a dangerous window of vulnerability.

2. High Cost of Commercial Software

Commercial enterprise monitoring solutions carry heavy licensing fees, making them inaccessible for SMEs.

Core Objectives

1

Emulate Infrastructure

Design an enterprise network core with strict Port Security inside EVE-NG.

2

Develop Monitoring Daemon

Develop a Python socket daemon parsing Syslog via UDP 514 using Regex.

3

Automate Remediation

Automate CLI mitigation via Netmiko SSH and push Discord Webhook alerts.

Scenario Demonstration

Phase 1: The Breach

An unauthorized machine connects to the enterprise switch, injecting an unregistered MAC address.

Phase 2: Syslog Detection

The Python Daemon catches UDP 514 packets. The Regex engine filters out the exact violation signature.

Phase 3: Automated Mitigation

The script establishes SSH via Netmiko, shutting down the port and alerting admins via Discord.
